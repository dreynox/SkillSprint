## Target Statement
College-level programmers often use fragmented platforms for coding practice, contests, and progress tracking, which reduces engagement and makes skill development inconsistent. There is a need for a unified portal that supports real-time challenges, transparent rankings, and badge-based motivation to improve participation and measurable learning outcomes.

## Completion Checklist

- [x] Unified portal for coding, contests, quizzes, profile, and admin operations
- [x] Transparent rankings with points-based leaderboard logic
- [x] Badge-based motivation (Starter, Intermediate, Advanced, Pro, Elite)
- [x] Real-time challenge support through live contest window countdowns and automatic leaderboard refresh
- [x] Measurable outcomes via quiz scores, contest submissions, participation counts, and total points
